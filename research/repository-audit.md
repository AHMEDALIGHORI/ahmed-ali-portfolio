# Repository Audit — Initial Evidence

Source: https://github.com/AHMEDALIGHORI?tab=repositories

The visible repository list confirms several high-potential technical and visual candidates. The strongest initial candidates are **Nimbus-Keyword-Webiste** (Next.js, Three.js, Prismic, GSAP, Stripe Checkout), **Speech-Thearpy-Project** (AI-powered speech screening and communication practice), **capitolium-burgers** (cinematic restaurant experience with Next.js, GSAP, Lenis), **PlantPot** (React Three Fiber interactive 3D portfolio clone), **Webgel-Studio-WEBGEL** (multi-page GSAP motion study based on an identified source), and **FIFA-WORLD-WEBSITE-** (React/Vite interactive sticker album clone).

Initial audit rule: projects identified as faithful clones will not be presented as original commissioned work. If selected, they will be clearly positioned as **creative-engineering studies** and credited to the original reference in their case-study context. Original projects with independently defined product problem and technical evidence will take priority in the homepage selection.

## Repository Documentation Findings

### Nimbus Keyboards

Repository: https://github.com/AHMEDALIGHORI/Nimbus-Keyword-Webiste

An original, technically substantial commerce concept built with Next.js 15, React 19, TypeScript, Three.js / React Three Fiber, GSAP, Prismic, and Stripe Checkout. The documented feature set includes a real-time keyboard configurator, selectable keycap themes and sound-switch variants, CMS slices, server-created checkout sessions, dynamic SEO metadata, and reduced-motion handling. It is a strong visual and systems-focused portfolio candidate; the case study should describe it as a concept storefront unless a public production deployment is supplied.

### Speech Therapy Project

Repository: https://github.com/AHMEDALIGHORI/Speech-Thearpy-Project

An original, mission-led AI communication-practice public demo for adults. The project documents non-diagnostic boundaries, consent and privacy flows, safety escalation rules, vetted knowledge retrieval, optional transcription, a provider-fallback design, versioned database migrations, and test coverage. A public demo URL is documented in the README. This is the strongest product-thinking and responsible-AI candidate, but all website copy must preserve its own disclosed limitations and avoid clinical claims.

### Capitolium

Repository: https://github.com/AHMEDALIGHORI/capitolium-burgers

A visual creative-engineering concept built with Next.js, GSAP, Lenis, and Tailwind. Documentation describes a custom loader, page-level motion systems, an interactive menu cart, and multiple story-led routes. The README discloses that the project was rebranded from a CRAV reference experience, so it will be labeled as a **motion study / concept adaptation** rather than original brand work.

### Existing Portfolio Repository

Repository: https://github.com/AHMEDALIGHORI/Ahmed-Ali-Ghori-Portofilo-Webiste

The repository documents a separate portfolio implementation and identifies RozgarSync, Medical Assistant, VisionAI Pro, and Capitolium as featured projects. It contains a live portfolio URL, but the README notes that owner-only access may be required. It also establishes the author email `ahmedalighori92@gmail.com`, which will be used in the upgraded contact experience in preference to the placeholder address used in the first portfolio delivery.

### RozgarSync

Repository: https://github.com/AHMEDALIGHORI/-RozgarSync-AI-Orchestrator

An original bilingual AI service-platform concept for Pakistan’s informal gig economy. The repository describes five specialized agents, an event bus, circuit breakers, confidence scoring, tamper-evident audit trails, Firebase services, English/Urdu interface support, PWA behavior, and associated workflow APIs. It is the strongest systems-design project in the audit. Portfolio copy will present its stated market, wage, safety, and social-security logic as a **concept architecture**, rather than a deployed real-world service.

### Medical Assistant Bot

Repository: https://github.com/AHMEDALIGHORI/Medical-Assistant-Bot

An academic NLP project that combines Streamlit, DistilBERT intent classification, ChromaDB retrieval, Ollama generation, citations, and emergency keyword escalation. The README lists model-evaluation figures and clear general-information-only limitations. It will be included in the laboratory index, not the primary featured set, to maintain portfolio focus and prevent the project from being mistaken for a clinical product.

### VisionAI Pro

Repository: https://github.com/AHMEDALIGHORI/VisionAi-

An original Python computer-vision prototype combining OpenCV, YOLOv8, MediaPipe, gesture control, product recognition, sign-language experiments, and unit tests. It is best presented as a **technical lab experiment** with an explicit experimental-use note rather than as an accessibility-critical translation service.

### FIFA World Cup Player Album

Repository: https://github.com/AHMEDALIGHORI/FIFA-WORLD-WEBSITE-

The documentation clearly identifies this work as a pixel-accurate clone using a mirrored third-party production bundle and trademarks. It will not appear in the professional portfolio project selection. It can be retained privately as a learning exercise but is not appropriate as public professional evidence.
